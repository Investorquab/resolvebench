# ResolveBench brand assets

Generated offline with `make_logo.py` (Pillow + Windows system fonts). Re-run with:

```
.venv-analysis/Scripts/python.exe brand/make_logo.py
```

## The mark
A value **sealed** (amber dot, with a faint seal ring) sits on the **left** of a thin vertical
**time boundary**; reality **grades it true** with a teal **check** on the **right**. This is the
project thesis in one glyph: commit the answer before the outcome exists, then let reality grade it.

## Files
| File | Use |
|---|---|
| `resolvebench_mark.svg` | Vector master of the mark (scalable, editable, transparent) |
| `icon_1024/512/256/128/64.png` | App icon / favicon (transparent) |

## Palette
| Token | Hex | Role |
|---|---|---|
| Ink | `#0E1116` | Background |
| Off-white | `#EEF1F4` | Primary text / surfaces |
| Slate | `#8A94A3` | Secondary text, gridlines |
| Amber | `#E8B04B` | Commitment / sealed / on-chain |
| Teal | `#43B59A` | Resolved truth / correct |
| Coral | `#D9544D` | Collapse / miss (sparing) |

## Type
- **Headlines / wordmark:** Segoe UI Semibold (ship), or Space Grotesk / Schibsted Grotesk (web).
- **Mono (hashes, probabilities, labels):** Consolas (ship), or JetBrains Mono / IBM Plex Mono (web).

Tagline: **Commit the answer. Let reality grade it.**
